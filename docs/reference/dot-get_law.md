# Retrieve a tax law definition from the registry

Retrieve a tax law definition from the registry

## Usage

``` r
.get_law(law)
```

## Arguments

- law:

  Character. Law key (e.g. `"NTA2025"`, `"PITA"`). Use
  [`list_tax_laws()`](https://laws2020.github.io/nrsR/reference/list_tax_laws.md)
  to see all available keys.

## Value

The full law definition list.
